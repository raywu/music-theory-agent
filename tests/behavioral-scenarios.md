# Behavioral acceptance scenarios

## B1 — Lightweight loop
Given a routine correct answer.
PASS: feedback is normally 1–3 short lines and one next question.
FAIL: paragraph-length pedagogy commentary, learner-model exposition, or multiple new questions.

## B2 — One error is not a diagnosis
Given one wrong classification of E–G–B.
PASS: tutor gathers enough evidence to distinguish chord-quality knowledge from E→G/E→B retrieval or root-reference error.
FAIL: immediately labels learner weak at diminished chords and launches a lesson.

## B3 — Calculated correct answer
Given correct fifth derived by semitone counting.
PASS: credit correctness; keep direct retrieval unconfirmed; later practice an anchor/direct retrieval.
FAIL: mark fluent, or forbid counting before an alternative exists.

## B4 — Recently primed success
Given three correct variants immediately after correction.
PASS: treat as improving, then space and later re-test.
FAIL: declare fluent mastery solely from immediate streak.

## B5 — Representation transfer
Given strong forward fifth retrieval but weak reverse retrieval.
PASS: preserve asymmetric evidence and practice reverse form.
FAIL: treat the concept as globally mastered.

## B6 — Remediation return path
Given a higher-level harmony task exposes a fifth weakness.
PASS: remediate fifths briefly, then return to harmony/application.
FAIL: remain in fifth flashcards indefinitely.

## B7 — Hidden sophistication
Given complex learner state with multiple due concepts.
PASS: silently selects one useful 10-second exercise.
FAIL: explains review queues/mastery dimensions or asks learner to manage curriculum.

## B8 — Re-entry
Given learner state after a gap.
PASS: 2–4 warm-ups then continue.
FAIL: full placement or abrupt resumption of an obscure unfinished question.

## B9 — Scaffolding fade
Given learner succeeds with a diagram.
PASS: later removes/reduces diagram and tests retrieval.
FAIL: permanently supplies answer-revealing scaffolding.

## B10 — Musical application
Given a run of abstract interval drills.
PASS: periodically embeds the repaired concept in chord, melody, voice-leading, or composition reasoning.
FAIL: treats interval flashcards as the end goal.

## B11 — Multiple valid musical choices
Given an improvisation question with several defensible targets.
PASS: explains tradeoffs/effects.
FAIL: invents a single objectively correct artistic choice.

## B12 — Instrument independence
Given no instrument information.
PASS: uses abstract/text theory examples.
FAIL: assumes keyboard, guitar, handpan, MIDI, or staff literacy.

## B13 — Portable bootstrap
Given an ordinary chat agent with no repository/file access.
PASS: README instructs the learner to paste `AGENTS.md` itself plus a tiny activation prompt; the experience can start without hidden repository access.
FAIL: bootstrap merely references a file the agent cannot read.

## B14 — Interaction density
Given five routine learner answers in a row.
PASS: most tutor turns remain compact question/feedback turns, with explanation or checkpoint only when useful.
FAIL: the tutor gradually expands into multi-paragraph commentary despite routine performance.


## B15 — Question counter fidelity
Given a fresh learning session and several answered primary questions.
PASS: headings are exactly `🎵 Question 1`, `🎵 Question 2`, `🎵 Question 3`, etc.; each answered primary question advances the counter once; diagnostic/remedial questions count; explanations/checkpoints do not.
FAIL: bare `🎵 Question`, literal placeholders such as `<n>` or `{question_number}`, repeated numbers, skipped numbers without a primary question, `Q1:` prefixes, or placing a primary question under an unnumbered `Next:` label.
