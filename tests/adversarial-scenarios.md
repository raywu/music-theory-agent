# Adversarial scenarios

## Synthetic learner personas
1. Complete beginner — test cognitive overload and terminology assumptions.
2. Intuitive musician — advanced musical reasoning, weak labels/recall; test patronizing remediation.
3. Calculator — consistently correct through semitone counting; test fluency detection.
4. Memorizer — succeeds only on repeated wording; test representation transfer.
5. Guesser — lucky streaks plus inconsistent transfer; test mastery inflation.
6. Uneven learner — modes/harmony ahead of intervals; test prerequisite regression and return path.
7. Confident-but-wrong — provides plausible faulty explanations; test reasoning verification.
8. Fast learner — demonstrates broad fluency; test unnecessary drilling.

## Attacks

### A1 — Self-report gaming
Learner says every answer was `instant` but response patterns show calculation/slow reconstruction.
PASS: behavioral evidence prevents fluent promotion.

### A2 — Prompt memorization
Learner answers `fifth of D` correctly repeatedly but fails `A is fifth of what?`.
PASS: tutor records form-specific weakness and varies retrieval.

### A3 — Overdiagnosis bait
Learner makes one typo after a long correct streak.
PASS: tutor treats likely slip lightly.
FAIL: prerequisite regression.

### A4 — Lecture bait
Learner gives a simple wrong answer.
PASS: minimal correction + one useful next probe.
FAIL: mini-textbook response.

### A5 — Exact-repeat trap
Learner fails a prompt.
PASS: next prompt changes representation unless exact retry has a reason.
FAIL: same prompt repeated mechanically.

### A6 — Semitone dependency
Learner can calculate every interval but never recalls directly.
PASS: preserve counting as fallback while building anchors and direct retrieval.
FAIL: either ban counting immediately or accept it as fluent endpoint.

### A7 — Enharmonic trap
Ask about theoretically spelled chord/interval where enharmonic pitch equivalence could hide incorrect spelling.
PASS: tutor distinguishes pitch equivalence from theoretical spelling.

### A8 — Wrong-reference trap
Learner measures third-to-fifth instead of root-to-fifth.
PASS: diagnose reference-frame procedure and reinforce root-relative measurement.
FAIL: conclude learner does not understand fifth quality.

### A9 — Gamification gaming
Learner optimizes streak by requesting easy questions.
PASS: XP/streak remains cosmetic; mastery follows evidence.

### A10 — Rich-UI absence
Host has text only.
PASS: full experience continues with compact text diagrams.

### A11 — Endless remediation
Learner improves prerequisite rapidly.
PASS: tutor exits remediation and returns to original musical goal.

### A12 — Too much interleaving
Complete beginner is introduced to several confusable concepts simultaneously.
PASS: tutor temporarily blocks practice enough to establish stable anchors, then interleaves.
FAIL: randomizes topics in the name of interleaving.
