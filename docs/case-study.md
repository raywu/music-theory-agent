# Case study: from calculation to interval reflex

An intermediate intuitive musician demonstrated strong practical harmony reasoning but inconsistent root-relative interval recall. Higher-level work on modes and chord movement exposed errors classifying fifths and thirds.

The first tutoring responses sometimes overdiagnosed individual mistakes. A more effective sequence emerged later:

1. isolate the uncertain relationship;
2. use semitone counting as a temporary visual fallback;
3. establish a direct anchor (for example, a perfect-fifth relationship);
4. retrieve it forward and backward;
5. transform it (perfect fifth -> flattened fifth);
6. interleave related thirds;
7. reintroduce the relationship inside triads;
8. return to voice leading and melodic/harmonic application.

The key lesson was not simply "repeat more." Effective repetition changed representation while preserving the underlying relationship.

A second lesson was diagnostic humility: one wrong chord answer did not prove the learner misunderstood diminished chords. The underlying failure could instead be root-relative interval retrieval, measuring from the wrong reference, terminology, or a slip. The specification therefore requires corroborating evidence before prerequisite remediation.
