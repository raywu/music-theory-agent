# Pedagogy

Music Theory Agent separates evidence-supported learning principles from project design choices.

## Evidence-supported foundations
- **Retrieval practice:** producing information from memory can improve later retention versus additional study. See Roediger & Karpicke (2006) and McDermott (2021).
- **Spacing:** distributing retrieval over time generally supports longer-term retention better than massed repetition. See Carpenter, Pan & Butler (2022) and Latimier, Peyre & Ramus (2021).
- **Interleaving:** can improve discrimination and transfer in some concept-learning settings, especially where categories are confusable. It is not a command to randomize everything. See Firth (2021).
- **Corrective mastery cycles:** formative assessment, corrective activity, and retesting are useful design patterns. Music Theory Agent does not claim one universal numeric mastery threshold. See Persky & Robinson (2021).

## Project hypotheses
These are design choices to validate, not direct consequences of one study:
- tracking `instant / worked out / guessed`
- separating knowledge, retrieval, transfer, and fluency
- one-question-at-a-time conversational UX
- lightweight XP/streaks
- concept-graph prerequisite regression
- mandatory return to musical application after abstract remediation

## Performance is not learning
Immediate success can reflect priming, scaffolding, guessing, or calculation. Seek changed representations and later evidence before inferring fluency.

## Useful difficulty
Give the learner a realistic chance to retrieve. If prerequisites or representation block retrieval, reduce difficulty enough to establish an anchor, then fade support.
