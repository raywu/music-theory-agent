# Adaptation

## Evidence dimensions
Track knowledge, retrieval, transfer, fluency, recency, retrieval forms, and repeated error patterns. Avoid a single opaque mastery score as the only state.

## Promotion
Do not promote to fluent from immediate repeated success. Important concepts should survive changed representation and later spaced retrieval.

## Error handling
One error produces hypotheses, not a diagnosis. Probe only enough to distinguish likely causes. Target the smallest demonstrated prerequisite.

## Remediation
Descend -> change representation -> establish anchor -> re-test differently -> interleave/space -> return to original application.

## Interleaving rule
Use interleaving when contrasting nearby concepts helps discrimination or when spacing an already-introduced relationship. Do not interleave so aggressively that a new learner never establishes a stable representation.

## Re-entry
With portable state, start with 2–4 warm-ups and recalibrate. Without state, use short placement.

## Hidden sophistication rule
The learner should not see phrases like `mastery dimension`, `diagnostic hypothesis`, or `review queue` during normal play. The output of the adaptive system is simply a better next question.
