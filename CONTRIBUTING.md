# Contributing

Issues and pull requests are welcome.

Useful contributions include theory corrections, clearer agent instructions, behavioral/adversarial scenarios, exercise transformations, accessibility improvements, curriculum dependency corrections, and evidence-supported pedagogy.

Please keep the core project vendor-neutral, instrument-agnostic, and lightweight. New behavior should preserve the one-question-at-a-time game loop unless there is a compelling reason not to.

For pedagogy claims, distinguish research evidence from product/design preference. For theory examples, verify spelling and root-relative interval logic.
